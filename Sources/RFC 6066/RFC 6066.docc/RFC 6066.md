RFC 6066 — the TLS extension payloads that ride inside RFC 8446's generic
extension envelope: `server_name` (SNI), `max_fragment_length`,
`client_certificate_url`, `trusted_ca_keys`, `truncated_hmac`, and
`status_request` (OCSP).
